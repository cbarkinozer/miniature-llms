# Causal Multihead Attention

Causal Multihead Attention is a core component of transformer architectures that enables the model to process information through multiple attention heads in parallel, allowing it to learn different relationships and patterns within the input sequence simultaneously. The **causal** property ensures that each token can only attend to itself and previous tokens, preventing access to future information during autoregressive generation and making the model suitable for language modeling tasks.

In the original Transformer architecture proposed by Vaswani et al. (2017), positional information was incorporated using **Absolute Positional Encoding (APE)**, which was added to the input embeddings before they were passed into the attention mechanism. In this implementation, **Rotary Positional Embeddings (RoPE)** are integrated directly within the attention computation instead. RoPE rotates the query and key representations based on their positions, allowing positional relationships to be encoded naturally during attention rather than being injected into the input embeddings.

This change is important because RoPE preserves relative positional information more effectively, improves the model's ability to generalize to longer sequence lengths, and has become the standard positional encoding method in many modern large language models. By incorporating RoPE inside the Causal Multihead Attention module, the positional information is applied where the query-key interactions are computed, addressing the absence of positional information in the attention calculation itself and resulting in more effective sequence modeling.
