## Mamba and State Space Models (SSMs)

Mamba is a neural network architecture based on State Space Models (SSMs), a class of sequence models designed to efficiently process long sequences without relying on the quadratic-cost self-attention mechanism used in transformers. Instead of computing pairwise interactions between every pair of tokens, an SSM maintains a compact hidden state that is continuously updated as new tokens arrive. This hidden state acts as a compressed memory of all previously seen information, allowing the model to capture long-range dependencies while processing the sequence in a linear, recurrent fashion.

Conceptually, rather than storing and comparing every token with every other token through an attention matrix, Mamba processes tokens one at a time using the pattern Input → State Update → Hidden State → Output. At each step, the current hidden state is updated based on the new input and then used to produce the output, after which only the updated state needs to be carried forward. As a result, memory usage and computation scale approximately linearly with sequence length (O(T)), rather than quadratically (O(T²)) as in standard attention mechanisms. This makes Mamba particularly well-suited for very long contexts where constructing a full T × T attention matrix would be prohibitively expensive.

A key innovation of Mamba over earlier State Space Models is its selective state mechanism. Traditional linear SSMs use fixed state transition dynamics, limiting their ability to selectively retain or discard information. Mamba introduces input-dependent parameters, allowing the model to dynamically decide what information should be remembered, updated, or forgotten based on the current token. In effect, the hidden state behaves as a learned memory whose behavior changes with the input, giving the architecture greater expressive power while preserving linear-time computation.

The primary advantage of Mamba is that it provides significantly better scalability for long-sequence processing while maintaining high computational efficiency. Because it avoids constructing and storing large attention matrices, it requires substantially less memory and can process much longer contexts with lower hardware requirements. Its sequential state updates also enable efficient streaming and autoregressive inference, making it attractive for applications involving long documents, audio, video, and time-series data.

Like Flash Attention, Mamba's practical performance relies heavily on hardware-aware implementation. Modern implementations use highly optimized fused GPU kernels—often written in Triton or custom CUDA—to efficiently perform state updates and minimize memory movement between high-bandwidth memory (HBM) and fast on-chip memory (SRAM). However, unlike Flash Attention, which computes the exact same attention operation more efficiently, Mamba represents a fundamentally different sequence modeling architecture that replaces attention altogether with a learned state-space recurrence. As a result, it offers excellent scalability and efficiency for long contexts but introduces additional architectural complexity and different trade-offs compared to transformer-based models.
